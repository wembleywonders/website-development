# 🔧 STEMgineers — Assessment Criteria

## Badge 1: Digital Literacy Explorer (Explorer)

### Assessment Criteria

| Ref | Criterion | Evidence Required | Pass Criteria |
|-----|-----------|-------------------|---------------|
| DL1.1 | Navigate digital environments | Observation | Uses file systems, browsers effectively |
| DL1.2 | Understand programming concepts | Code samples | Variables, loops, conditionals demonstrated |
| DL1.3 | Write functional code | 3 programs | All programs run without errors |
| DL1.4 | Debug simple errors | Observation | Can identify and fix basic bugs |
| DL1.5 | Complete working project | Project demo | Project functions as intended |
| DL1.6 | Document learning journey | Learning log | Regular entries, reflection shown |

## Badge 2: Maker Engineer (Builder)

### Assessment Criteria

| Ref | Criterion | Evidence Required | Pass Criteria |
|-----|-----------|-------------------|---------------|
| ME1.1 | Understand electronic components | Quiz/verbal | 80% accuracy |
| ME1.2 | Build functional circuit | Working circuit | Safe, functional build |
| ME1.3 | Integrate hardware and software | Project | Both elements working together |
| ME1.4 | Document build process | Documentation | Step-by-step with photos |
| ME1.5 | Create circuit diagrams | Schematics | Accurate, readable diagrams |
| ME1.6 | Present project | Presentation | Clear explanation, Q&A handled |
| ME1.7 | Receive peer feedback | Feedback forms | Constructive engagement |

## Practical Project Standards

All major projects must:
- Function as intended
- Be safe to operate
- Include documentation
- Demonstrate learning outcomes
- Be presented to peers
