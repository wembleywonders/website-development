# 🔧 STEMgineers — Evidence Requirements

## Badge 1: Digital Literacy Explorer

| Evidence Type | Format | Quantity |
|---------------|--------|----------|
| Code samples | .py / .js files | 3 minimum |
| Project demonstration | Video (2-5 mins) | 1 |
| Learning log | PDF | 1 (weekly entries) |
| Assessor observation | Signed form | 1 |
