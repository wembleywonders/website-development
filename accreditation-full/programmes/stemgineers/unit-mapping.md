# 🔧 STEMgineers — OCN Unit Mapping Document

## Programme Overview

**Programme Name**: STEMgineers  
**Tagline**: "Build. Code. Innovate."  
**Target Age**: 11-24  
**Delivery Mode**: Blended (workshops + online learning + maker space)

## Qualification Pathway

```
Digital Literacy Explorer Badge (Explorer)
        ↓
Maker Engineer Badge (Builder)
        ↓
OCN Award in STEM Skills (Entry 3) — 6 credits
        ↓
AI Explorer Badge (Innovator)
        ↓
Eco Innovator Badge (Leader)
        ↓
OCN Certificate in Digital Skills for Work (Level 2) — 15 credits
        ↓
Digital Support Technician Apprenticeship (Level 3)
```

---

## Internal Badge → OCN Unit Mapping

### Badge 1: Digital Literacy Explorer (Explorer)

**Internal Requirements**:
- Complete digital literacy fundamentals
- Write and run first code program
- Build a simple project (LED, game, etc.)

**Mapped OCN Units** (Entry 3 / Level 1):

| OCN Unit Code | Unit Title | Credit Value | GLH |
|---------------|------------|--------------|-----|
| STEM-E3-01 | Digital Literacy Fundamentals | 2 | 15 |
| STEM-E3-02 | Introduction to Coding | 2 | 15 |
| STEM-L1-01 | Creating Digital Solutions | 2 | 15 |

**Evidence Requirements**:
- Code samples (minimum 3 programs)
- Working project demonstration
- Learning log
- Assessor observation record

---

### Badge 2: Maker Engineer (Builder)

**Internal Requirements**:
- Complete a functional hardware project
- Document the build process
- Present at showcase event

**Mapped OCN Units** (Level 1/2):

| OCN Unit Code | Unit Title | Credit Value | GLH |
|---------------|------------|--------------|-----|
| STEM-L1-02 | Electronics Fundamentals | 3 | 25 |
| STEM-L1-03 | Project Documentation | 2 | 15 |
| STEM-L2-01 | Building Hardware Projects | 4 | 30 |

**Evidence Requirements**:
- Working prototype (video demonstration)
- Build documentation (step-by-step)
- Circuit diagrams/schematics
- Presentation recording
- Peer feedback

---

### Badge 3: AI Explorer (Innovator)

**Internal Requirements**:
- Build a chatbot or AI-assisted tool
- Complete data ethics module
- Create solution for real community problem

**Mapped OCN Units** (Level 2):

| OCN Unit Code | Unit Title | Credit Value | GLH |
|---------------|------------|--------------|-----|
| STEM-L2-02 | Introduction to AI and Machine Learning | 3 | 25 |
| STEM-L2-03 | Data Ethics and Responsible Technology | 2 | 15 |
| STEM-L2-04 | Community Problem Solving with Technology | 3 | 25 |

**Evidence Requirements**:
- AI project demonstration (live or video)
- Ethics reflection (500+ words)
- Community impact statement
- Technical documentation

### Badge 4: Eco Innovator (Leader)

**Internal Requirements**:
