# 🎙️ G-Tech Casters — Evidence Requirements

## Overview

This guide explains what evidence learners need to collect for each badge and how to submit it for assessment.

---

## Evidence Collection Principles

1. **Authenticity**: All content must be original work
2. **Technical Quality**: Meet minimum audio/visual standards
3. **Rights Cleared**: All music/samples must be licensed or royalty-free
4. **Consent**: All participants must provide documented consent

---

## Badge 1: Podcast Explorer (Explorer)

### Required Evidence

| Evidence Type | Description | Format | Quantity |
|---------------|-------------|--------|----------|
| Audio Recordings | Raw recording samples | WAV/MP3 | 3 minimum |
| Edited Segment | 5-minute edited piece | MP3 | 1 |
| Published Content | Live on Rayd-yo | URL link | 1 |
| Equipment Observation | Assessor checklist | Signed form | 1 |
| Reflective Log | Learning reflection | PDF/Word | 1 |

### Recording Sample Requirements

Each recording sample should demonstrate:
- Clear speech
- Appropriate levels (-12dB to -6dB peaks)
- Minimal background noise
- Duration: 1-3 minutes each

### Edited Segment Checklist

Your 5-minute segment must include:
- ☐ Introduction (who you are, what this is about)
- ☐ Main content (structured information or story)
- ☐ Conclusion (summary or call to action)
- ☐ Clean edits (no awkward cuts)
- ☐ Consistent audio levels
- ☐ Optional: Background music (royalty-free)

### Artwork Specifications

Cover artwork requirements:
- Size: 3000 x 3000 pixels (square)

### Required Evidence

| Evidence Type | Description | Format | Quantity |
|---------------|-------------|--------|----------|

### Leadership Journal Prompts

Each entry (minimum 300 words) should address:

1. **Situation**: What leadership challenge did you face?
2. **Behaviour**: How did you respond?
3. **Impact**: What was the outcome?
4. **Reflection**: What did you learn about yourself as a leader?
5. **Application**: How will this inform future leadership?

## Quality Standards Quick Reference

| Element | Standard |
|---------|----------|
| Audio levels | -16 LUFS (integrated) |
| Peak levels | -1dB maximum |
| Sample rate | 44.1kHz or 48kHz |
| Bit rate (MP3) | 192kbps minimum |
| Artwork | 3000x3000px, PNG/JPEG |
| Video | 720p minimum, clear audio |
