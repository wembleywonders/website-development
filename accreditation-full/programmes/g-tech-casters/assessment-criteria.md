# 🎙️ G-Tech Casters — Assessment Criteria

## Overview

This document defines the assessment criteria for each badge level in the G-Tech Casters programme. Assessors use these criteria to evaluate learner evidence and determine badge readiness.

---

## Badge 1: Podcast Explorer (Explorer)

### Learning Outcomes

By the end of this badge, learners will be able to:
1. Operate basic audio recording equipment
2. Perform fundamental audio editing tasks
3. Publish content to digital platforms
4. Reflect on their creative development

### Assessment Criteria

| Ref | Criterion | Evidence Required | Assessor Checklist |
|-----|-----------|-------------------|-------------------|
| PE1.1 | Set up microphone correctly | Assessor observation | ☐ Correct positioning |
| PE1.2 | Achieve acceptable audio levels | Recording sample | ☐ Levels appropriate |
| PE1.3 | Minimise background noise | Recording sample | ☐ Noise managed |
| PE1.4 | Handle equipment safely | Assessor observation | ☐ Safe handling |
| PE2.1 | Import audio into editing software | Assessor observation | ☐ Successful import |
| PE2.2 | Cut and trim audio clips | Edited project | ☐ Clean cuts |
| PE2.3 | Adjust volume levels | Edited project | ☐ Consistent levels |
| PE2.4 | Export in appropriate format | Exported file | ☐ Correct format |
| PE3.1 | Create account on Rayd-yo | Platform screenshot | ☐ Account active |
| PE3.2 | Upload content with metadata | Published content | ☐ Metadata complete |
| PE3.3 | Add appropriate title and description | Published content | ☐ Quality metadata |
| PE4.1 | Complete reflective log | Written reflection | ☐ Thoughtful reflection |
| PE4.2 | Identify areas for improvement | Written reflection | ☐ Self-awareness shown |

### Audio Quality Standards

Submitted recordings must meet:
- Clear speech (understandable throughout)
- Consistent volume (no major peaks/dips)
- Minimal background noise
- No technical faults (clicks, pops, distortion)

## Badge 2: Producer (Builder)

### Learning Outcomes

By the end of this badge, learners will be able to:
1. Plan structured audio content
2. Apply advanced editing techniques
3. Conduct recorded interviews professionally
4. Create visual brand assets

### Assessment Criteria

| Ref | Criterion | Evidence Required | Assessor Checklist |
|-----|-----------|-------------------|-------------------|
| PR1.1 | Create episode outline/rundown | Planning document | ☐ Clear structure |
| PR1.2 | Identify target audience | Planning document | ☐ Audience defined |
| PR1.3 | Plan content duration accurately | Comparison: plan vs final | ☐ Within 20% of plan |
| PR2.1 | Apply EQ to improve audio | Project file | ☐ Appropriate EQ |
| PR2.2 | Use compression effectively | Project file | ☐ Balanced dynamics |
| PR2.3 | Remove noise/unwanted sounds | Project file | ☐ Clean audio |
| PR2.4 | Add music/sound effects appropriately | Project file | ☐ Licensed content used |
| PR2.5 | Create smooth transitions | Final episode | ☐ Professional transitions |
| PR3.1 | Prepare interview questions | Question list | ☐ Thoughtful questions |
| PR3.2 | Obtain consent from interviewee | Signed consent form | ☐ Consent documented |
| PR3.3 | Conduct interview professionally | Recording | ☐ Professional manner |
| PR3.4 | Use follow-up questions effectively | Recording | ☐ Active listening shown |
| PR4.1 | Create cover artwork | Image file | ☐ Correct dimensions |
| PR4.2 | Artwork reflects content/brand | Image file | ☐ Appropriate design |
| PR4.3 | Write compelling episode description | Published metadata | ☐ Engaging copy |

### Episode Quality Standards

15-minute episode must include:
- Clear introduction (who, what, why)
- Structured middle content
- Defined ending/call to action
- Consistent audio quality throughout
- Appropriate music/transitions

## Badge 3: Broadcaster (Innovator)

### Learning Outcomes

By the end of this badge, learners will be able to:
1. Present live content under broadcast conditions
2. Produce a coherent content series
3. Grow and engage an audience
4. Analyse performance metrics

### Assessment Criteria

| Ref | Criterion | Evidence Required | Assessor Checklist |
|-----|-----------|-------------------|-------------------|
| BC1.1 | Set up for live broadcast | Pre-show checklist | ☐ Setup verified |
| BC1.2 | Present fluently for 30+ minutes | Live recording | ☐ Confident delivery |
| BC1.3 | Handle technical issues calmly | Recording/observation | ☐ Problem-solving shown |
| BC1.4 | Engage with live audience | Recording/chat log | ☐ Interaction evident |
| BC1.5 | Manage time effectively | Show timing | ☐ On-schedule |
| BC2.1 | Plan 4-episode series arc | Series outline | ☐ Coherent narrative |
| BC2.2 | Maintain consistent quality | All 4 episodes | ☐ Quality consistent |
| BC2.3 | Apply consistent branding | All 4 episodes | ☐ Brand cohesion |
| BC2.4 | Release on schedule | Publication dates | ☐ Schedule maintained |
| BC3.1 | Achieve 100+ plays | Analytics screenshot | ☐ Metric achieved |
| BC3.2 | Implement promotion strategy | Social media evidence | ☐ Active promotion |
| BC3.3 | Respond to audience feedback | Response examples | ☐ Engagement shown |
| BC4.1 | Analyse audience demographics | Analytics report | ☐ Data interpreted |
| BC4.2 | Identify successful content | Analytics report | ☐ Insights drawn |
| BC4.3 | Apply insights to future content | Reflection statement | ☐ Learning applied |

### Live Show Requirements

30-minute live show must demonstrate:
- Professional introduction
- Prepared content/running order
- Smooth transitions between segments
- Audience acknowledgment
- Time management
- Professional sign-off

## Badge 4: Media Leader (Leader)

### Learning Outcomes

By the end of this badge, learners will be able to:
1. Mentor new content creators
2. Lead programming schedules
3. Create training resources
4. Demonstrate leadership reflection

### Assessment Criteria

| Ref | Criterion | Evidence Required | Assessor Checklist |
|-----|-----------|-------------------|-------------------|
| ML1.1 | Guide 3 mentees through first episode | Mentoring logs | ☐ 3 mentees documented |
| ML1.2 | Provide constructive feedback | Feedback examples | ☐ Quality feedback |
| ML1.3 | Adapt approach to mentee needs | Reflection | ☐ Flexibility shown |
| ML1.4 | Mentees achieve Explorer badge | Badge records | ☐ Mentee success |
| ML2.1 | Create weekly programming schedule | Schedule document | ☐ Complete schedule |
| ML2.2 | Coordinate multiple contributors | Communication evidence | ☐ Coordination shown |
| ML2.3 | Ensure schedule coverage | Broadcast logs | ☐ No gaps |
| ML2.4 | Handle schedule changes | Change log | ☐ Issues managed |
| ML3.1 | Create written training guide | Document | ☐ Comprehensive guide |
| ML3.2 | Create video tutorial | Video file | ☐ Clear instruction |
| ML3.3 | Materials used by others | Usage evidence | ☐ Materials adopted |
| ML4.1 | Complete leadership journal | Journal entries | ☐ 5+ entries |
| ML4.2 | Identify leadership style | Reflection | ☐ Self-awareness |
| ML4.3 | Set development goals | Action plan | ☐ SMART goals |

### Programming Leadership Assessment

Weekly programming slot must demonstrate:
- Minimum 4 weeks of consistent programming
- At least 3 different contributors managed
- Schedule communicated clearly
- Contingency plans for gaps
- Quality standards maintained

## Technical Standards Reference

### Audio Specifications
- Sample rate: 44.1kHz or 48kHz
- Bit depth: 16-bit minimum
- Format: MP3 (192kbps+) or WAV
- Loudness: -16 LUFS (integrated)

### Artwork Specifications
- Dimensions: 3000x3000 pixels (square)
- Format: JPEG or PNG
- File size: Under 5MB
- Content: No explicit imagery without warning

## Reasonable Adjustments

Assessors may apply reasonable adjustments including:
- Extended time for live assessments
- Pre-recorded alternatives to live shows
- Written alternatives to verbal presentations
- Assistive technology support
- Flexible assessment scheduling

All adjustments must be documented and approved by the IQA.
