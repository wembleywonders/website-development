# 🎭 Kaywana's Court — OCN Unit Mapping Document

## Programme Overview

**Programme Name**: Kaywana's Court  
**Tagline**: "Stories. Stage. Legacy."  
**Target Age**: 11-24  
**Delivery Mode**: In-person workshops, rehearsals, performances

## Qualification Pathway

```
Character Workshop Badge (Explorer)
        ↓
Ensemble Member Badge (Builder)
        ↓
OCN Award in Performing Arts (Level 1) — 6 credits
        ↓
Featured Performer Badge (Innovator)
        ↓
Director Badge (Leader)
        ↓
OCN Certificate in Performance Skills (Level 2) — 18 credits
```

## Heritage Integration

Kaywana's Court uniquely preserves Caribbean performance traditions:

| Tradition | Integration |
|-----------|-------------|
| Oral storytelling | Elder interviews, story documentation |
| Caribbean theatre | Traditional performance styles |
| Carnival arts | Costume, movement, celebration |
| Folk traditions | Songs, dances, rituals preserved |
