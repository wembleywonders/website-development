# ♻️ Scrap Cat — Assessment Criteria

## Overview

This document defines the assessment criteria for each badge level in the Scrap Cat programme. Assessors use these criteria to evaluate learner evidence and determine badge readiness.

---

## Badge 1: Device Diagnostic (Explorer)

### Learning Outcomes

By the end of this badge, learners will be able to:
1. Identify common computing devices and their components
2. Recognise symptoms of common hardware and software faults
3. Use basic diagnostic tools and techniques
4. Document findings accurately

### Assessment Criteria

| Ref | Criterion | Evidence Required | Assessor Checklist |
|-----|-----------|-------------------|-------------------|
| DD1.1 | Identify at least 5 different device types | Device identification worksheet | ☐ Correctly identified |
| DD1.2 | Name key internal components (CPU, RAM, storage, PSU) | Labelled diagram or verbal assessment | ☐ Minimum 4 components |
| DD1.3 | Describe function of each component | Written or verbal explanation | ☐ Accurate descriptions |
| DD2.1 | Identify 3 common hardware fault symptoms | Diagnostic log entries | ☐ Symptoms correctly identified |
| DD2.2 | Identify 3 common software fault symptoms | Diagnostic log entries | ☐ Symptoms correctly identified |
| DD2.3 | Distinguish between hardware and software issues | Assessment scenario | ☐ Correct classification |
| DD3.1 | Use visual inspection techniques | Assessor observation | ☐ Safe and systematic |
| DD3.2 | Use basic diagnostic software | Assessor observation | ☐ Correct tool selection |
| DD3.3 | Interpret diagnostic results | Written analysis | ☐ Accurate interpretation |
| DD4.1 | Complete diagnostic template accurately | Completed template | ☐ All fields complete |
| DD4.2 | Take clear photographic evidence | Photo evidence | ☐ Minimum 3 photos |
| DD4.3 | Write clear fault description | Written description | ☐ Understandable to others |

### Grading

- **Pass**: All criteria marked as met
- **Refer**: 1-3 criteria not met (resubmission required)
- **Not Yet Competent**: 4+ criteria not met (additional support needed)

## Badge 2: Repair Apprentice (Builder)

### Learning Outcomes

By the end of this badge, learners will be able to:
1. Safely handle electronic components
2. Perform supervised repairs on common devices
3. Follow health and safety procedures
4. Communicate with device owners professionally

### Assessment Criteria

| Ref | Criterion | Evidence Required | Assessor Checklist |
|-----|-----------|-------------------|-------------------|
| RA1.1 | Demonstrate ESD precautions | Assessor observation | ☐ Consistent practice |
| RA1.2 | Use appropriate tools correctly | Assessor observation | ☐ Correct selection/use |
| RA1.3 | Handle components without damage | Assessor observation | ☐ No damage caused |
| RA2.1 | Complete 5 supervised repairs | Repair log with sign-off | ☐ 5 entries verified |
| RA2.2 | Repairs include at least 2 device types | Repair log | ☐ Variety demonstrated |
| RA2.3 | Repairs include hardware AND software | Repair log | ☐ Both types present |
| RA2.4 | Document repair process step-by-step | Repair log entries | ☐ Clear documentation |
| RA3.1 | Complete H&S induction | Signed checklist | ☐ Completed |
| RA3.2 | Identify hazards in repair environment | Written/verbal assessment | ☐ Key hazards identified |
| RA3.3 | Demonstrate safe disposal of e-waste | Assessor observation | ☐ Correct procedure |
| RA4.1 | Explain repair to device owner | Assessor observation or recording | ☐ Clear communication |
| RA4.2 | Obtain customer feedback | Feedback form | ☐ Feedback collected |
| RA4.3 | Handle dissatisfied customer scenario | Role play assessment | ☐ Professional response |

### Practical Assessment

**Supervised Repair Assessment**
- Learner completes one repair under direct observation
- Assessor completes observation checklist
- Time limit: 60 minutes
- Must demonstrate: safety, process, documentation, communication

## Badge 3: Fixer (Innovator)

### Learning Outcomes

By the end of this badge, learners will be able to:
1. Complete repairs independently
2. Mentor new participants
3. Contribute to community repair events
4. Articulate environmental impact of repair

### Assessment Criteria

| Ref | Criterion | Evidence Required | Assessor Checklist |
|-----|-----------|-------------------|-------------------|
| FX1.1 | Complete 10 independent repairs | Portfolio with evidence | ☐ 10 entries verified |
| FX1.2 | Repairs span 3+ device categories | Portfolio analysis | ☐ Variety demonstrated |
| FX1.3 | Success rate minimum 70% | Portfolio statistics | ☐ Rate calculated |
| FX1.4 | Handle complex multi-fault repairs | Portfolio evidence | ☐ At least 2 complex |
| FX2.1 | Guide newcomer through first repair | Mentoring log | ☐ Session documented |
| FX2.2 | Provide constructive feedback | Mentee feedback form | ☐ Positive feedback |
| FX2.3 | Adapt guidance to mentee needs | Reflection statement | ☐ Awareness shown |
| FX3.1 | Attend Repair Café event | Attendance record | ☐ Verified attendance |
| FX3.2 | Complete minimum 2 repairs at event | Event log | ☐ Repairs documented |
| FX3.3 | Engage positively with public | Event feedback | ☐ Positive engagement |
| FX4.1 | Calculate environmental impact | Impact statement | ☐ Metrics included |
| FX4.2 | Explain circular economy principles | Written/verbal assessment | ☐ Understanding shown |
| FX4.3 | Create sustainability content | Video or written piece | ☐ Content produced |

### Portfolio Requirements

The Fixer portfolio must include:
- Repair evidence for all 10 devices (before/after photos, fault description, solution)
- Video walkthrough of one complex repair (5-10 minutes)
- Mentoring log with mentee sign-off
- Repair Café participation certificate
- Sustainability impact statement (500+ words)

## Badge 4: Repair Leader (Leader)

### Learning Outcomes

By the end of this badge, learners will be able to:
1. Plan and lead repair sessions
2. Train new Repair Apprentices
3. Create learning resources
4. Reflect on leadership development

### Assessment Criteria

| Ref | Criterion | Evidence Required | Assessor Checklist |
|-----|-----------|-------------------|-------------------|
| RL1.1 | Create session plan | Written plan | ☐ Complete and realistic |
| RL1.2 | Lead Repair Café session | Assessor observation | ☐ Effective leadership |
| RL1.3 | Manage resources and time | Session evaluation | ☐ Well-managed |
| RL1.4 | Handle issues during session | Assessor observation | ☐ Problems resolved |
| RL2.1 | Train 3 new apprentices | Training log | ☐ 3 trainees documented |
| RL2.2 | Create training materials | Materials submitted | ☐ Quality materials |
| RL2.3 | Assess trainee competence | Assessment records | ☐ Fair assessment |
| RL2.4 | Receive positive trainee feedback | Feedback forms | ☐ Majority positive |
| RL3.1 | Create repair tutorial | Published content | ☐ Tutorial live |
| RL3.2 | Tutorial is accurate and clear | Quality review | ☐ Technically correct |
| RL3.3 | Tutorial accessible to beginners | Peer review | ☐ Beginner-friendly |
| RL4.1 | Complete reflective journal | Journal entries | ☐ Minimum 5 entries |
| RL4.2 | Identify leadership strengths | Reflection | ☐ Self-awareness shown |
| RL4.3 | Set development goals | Action plan | ☐ SMART goals set |

### Leadership Assessment

**Observed Session**
- Assessor observes full Repair Café session led by learner
- Minimum 2-hour session
- Minimum 3 community members served
- Assessment covers: planning, communication, problem-solving, team coordination

## Assessment Methods Summary

| Badge | Primary Methods | Secondary Methods |
|-------|-----------------|-------------------|
| Device Diagnostic | Written evidence, Observation | Verbal Q&A |
| Repair Apprentice | Practical observation, Log review | Role play |
| Fixer | Portfolio assessment, Event participation | Video evidence |
| Repair Leader | Observed session, Training evaluation | Reflective writing |

---

## Reasonable Adjustments

Assessors may apply reasonable adjustments including:
- Extended time for written assessments
- Verbal alternatives to written evidence
- Assistive technology support
- Flexible assessment scheduling
- Alternative evidence formats

All adjustments must be documented and approved by the IQA.

---

## Appeals Process

Learners may appeal assessment decisions within 10 working days. See Quality Assurance documentation for full appeals procedure.
