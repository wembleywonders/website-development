# ♻️ Scrap Cat — OCN Unit Mapping Document

## Programme Overview

**Programme Name**: Scrap Cat  
**Tagline**: "Reduce. Repair. Reuse."  
**Target Age**: 11-24  
**Delivery Mode**: Blended (in-person workshops + online hub)  

## Qualification Pathway

```
Device Diagnostic Badge (Explorer)
        ↓
Repair Apprentice Badge (Builder)
        ↓
Fixer Badge (Innovator)
        ↓
Repair Leader Badge (Leader)
        ↓
OCN Award in IT User Skills (Entry 3 / Level 1) — 6 credits
        ↓
OCN Certificate in IT Systems Support (Level 2) — 15 credits
        ↓
IT Support Technician Apprenticeship (Level 3)
```

## Internal Badge → OCN Unit Mapping

### Badge 1: Device Diagnostic (Explorer)

**Internal Requirements**:
- Complete device identification module
- Successfully diagnose 3 common device issues
- Document findings using diagnostic template

**Mapped OCN Units** (Entry 3 / Level 1):

| OCN Unit Code | Unit Title | Credit Value | GLH |
|---------------|------------|--------------|-----|
| IT-E3-01 | Understanding Computer Hardware | 2 | 15 |

## Quality Assurance

### Assessor Requirements
- Minimum Level 3 qualification in IT or related field
- CAVA or equivalent assessor qualification
- Industry experience in device repair

### Internal Verification
- Sample 25% of all assessments
- Standardisation meetings quarterly
- External verification by OCN London annually

### Evidence Storage
- Digital portfolios on platform
- Physical evidence photographed and uploaded
- Assessment records retained for 3 years
