# Wembley Wonders CIC — OCN LOCN Accreditation Framework

## Overview

This directory contains unit mapping documents for OCN London accreditation pathways. Our programmes ladder from internal badges through to recognised qualifications and apprenticeship standards.

## Accreditation Strategy

```
Internal Badges (Explorer → Builder → Innovator → Leader)
        ↓
OCN Awards (Entry 3 / Level 1) — 6-12 credits
        ↓
OCN Certificates (Level 2) — 13-24 credits
        ↓
Apprenticeship Standards (Level 3)
```
