# Pageturners — Activity Workbook
## Composition Craft with Balla Fasséké | Explorer Tier, Lesson 1

*Companion to: "Why Meter Exists." Complete after reading the lesson, not instead of it — this workbook assumes you already know what a stressed syllable and a formula-slot are.*

---

### How to use this workbook

Work through the activities in order. Each one builds on the last. Write directly in the blanks — there's no wrong answer as long as you're actually trying the mechanic, not performing it perfectly. This is Explorer tier: the goal is honest first attempts, not polish.

Time estimate: 30–40 minutes.

---

## Activity 1 — Find the Pulse

Pick any four-line piece you already know by heart — a nursery rhyme, a song chorus, an advert jingle. It doesn't need to be "poetry."

Write it here:

Line 1: ___________________________________________
Line 2: ___________________________________________
Line 3: ___________________________________________
Line 4: ___________________________________________

Now go line by line. Say each line out loud, slowly, and mark every syllable that lands with a natural stress. Use a `/` above stressed syllables and a `x` above unstressed ones, like this worked example:

```
x  /   x  /  x /  x  /
The morn-ing came and no one saw it rise
```

Mark your own four lines the same way:

Line 1: ___________________________________________
Line 2: ___________________________________________
Line 3: ___________________________________________
Line 4: ___________________________________________

**Question:** Do the same stress-patterns repeat, line to line? Circle: **YES / NO / PARTLY**

If yes — you've just found the metrical skeleton that makes it memorable. If no or partly — that's fine too. Not everything has strict meter, and noticing the *absence* of a pattern is just as useful a skill as spotting one.

## Activity 2 — Build Your Formula-Slot

Choose ONE of the three formula-slot shapes from the lesson:

- **[name], [epithet]**
- **as [natural image], so [human quality]**
- **[action verb], [action verb], and [consequence]**

Which one did you choose? _______________________________

Now use it TWICE, about two completely different subjects — a person you know, a place, a memory, anything. Keep the exact shape identical both times; only the content changes.

Use #1: ____________________________________________
Use #2: ____________________________________________

**Self-check:** Read both lines out loud back to back. Does the shape genuinely feel the same, even though the content is different? Circle: **YES / NO**

If no, look at where they diverge — that's usually where you accidentally added or dropped a beat. Try one more time if needed:

Use #3 (retry): ____________________________________

## Activity 3 — Break It on Purpose

This one teaches by contrast. Take Activity 1's original four lines and rewrite them so the meter is deliberately broken — add or remove syllables randomly, ignore the pattern entirely.

Broken Line 1: _____________________________________
Broken Line 2: _____________________________________
Broken Line 3: _____________________________________
Broken Line 4: _____________________________________

Try to say your broken version from memory after reading it twice. Then try the original again from memory after reading it twice.

**Which was easier to hold in your head?** Circle: **ORIGINAL / BROKEN**

Write one sentence on why, in your own words:

_____________________________________________________
_____________________________________________________

(If you answered "broken" — that's a genuinely interesting result, not a wrong one. Note what made it stick for you; it might mean you respond to a different memory mechanism than pure stress-pattern, which is worth knowing about your own process going forward.)

## Self-Assessment Checklist (Explorer tier evidence)

Before submitting, check that you have:

- [ ] Marked stress patterns on four real lines (Activity 1)
- [ ] Built one formula-slot and used it twice with different content (Activity 2)
- [ ] Compared broken vs. original meter and written a one-sentence reflection (Activity 3)
- [ ] Written answers in your own words, not copied from the lesson text

If all four are checked, this workbook page itself — Activities 1 through 3, completed — **is** your Explorer-tier submission. No separate write-up needed.
