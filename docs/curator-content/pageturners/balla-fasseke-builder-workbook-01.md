# Pageturners — Activity Workbook
## Composition Craft with Balla Fasséké | Builder Tier, Lesson 1

*Companion to: "Composing With a Bank." Complete after reading the lesson — this workbook assumes you can already identify a stress pattern and build a single formula-slot from Explorer tier.*

---

### How to use this workbook

Work through in order — each activity feeds the next, ending in a real opening stanza. Time estimate: 45–60 minutes.
