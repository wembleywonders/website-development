# Trubble n Bass — Evidence Requirements

## What Counts as Evidence

Evidence must be authentic (created by the learner), sufficient (covers all
criteria), current (produced during or after programme enrolment), and valid
(directly demonstrates the criterion).

### Acceptable Evidence Types

| Type | Description | Criteria Covered |
|------|-------------|------------------|
| Notated transcription | Written notation of an oral/folk source, credited | 1.1 |
| Original composition | Original notated or recorded piece | 1.1 |
| BeatMakerROV output | Beat/track file with tempo/key stated | 1.2 |
| Remix file | Deconstructed and rebuilt version of an existing track | 1.3 |
| AudioBay submission record | Technical checklist with reviewer sign-off | 1.4 |
| Genre research presentation | Written or recorded presentation, sourced | 2.1 |
| Live performance recording | Recorded or peer-witnessed performance in a defined role | 2.2 |
| Collaboration/rehearsal log | Dated log covering minimum 3 sessions | 2.3 |
| Artist development record | Documented development process | 2.4 |
| Developed member's confirmation | Peer-witness statement from the member developed | 2.4 |
| Final mix/master file | Distribution-spec-ready audio file | 3.1 |
| Airplay/gatekeeper submission | Submission record to Afua/Rayd-yo, with outcome | 3.2 |
| Capstone track/set | Complete original piece combining TNB-1/TNB-2 skills | 3.3 |
| Joystick portfolio entry | Live published entry with full metadata | 3.4 |

## Storage and Submission

All evidence stored in creator ILP. Evidence portfolio submitted via platform
assessment request. Assessor reviews within 10 working days.

## Peer Witness Requirement (Criterion 2.4 specifically)

Criterion 2.4 (Artist Development & A&R) is verified via the platform's
existing peer-witness requirement (required for Practitioner level and above
platform-wide) rather than a separate mechanism: the developed member's own
confirmation that their raw work was meaningfully advanced is the primary
evidence, alongside the developing member's documented process notes. This
also satisfies the Crew Log's "peer-facing showcase" touchpoint from the
cross-skill rotation gate (see `ww-skunkworks-impact-labs.md`) — Trubble n
Bass previously had no criterion producing that touchpoint explicitly.

## Authenticity Declarations

Creator signs an authenticity declaration for each unit submission
confirming:
- Work is their own
- Any collaboration is clearly identified (specifically relevant to 2.3 and
  2.4, where collaboration is the point of the criterion, not an exception to
  declare against)
- AI-assisted content is declared and the creative decisions were theirs
