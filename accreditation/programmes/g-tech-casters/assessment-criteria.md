# G-Tech Casters — Assessment Criteria

## Programme Overview
G-Tech Casters develops audio production and broadcasting skills through practical podcast and radio production. Assessment is competence-based — creators demonstrate skills through real outputs, not examinations.

## Assessment Areas

### Unit 1: Audio Production Fundamentals (Level 2, 3 credits)

**Learning Outcomes:**
1. Understand basic audio principles (frequency, dynamics, levels)
2. Operate audio recording and editing software
3. Apply quality control to audio outputs

**Assessment Criteria:**

| Criterion | Evidence Required | Pass Standard |
|-----------|-------------------|---------------|
| 1.1 Record audio to acceptable quality | Audio recording (min 3 minutes) | No clipping, -12dBFS average level |
| 1.2 Edit audio using non-destructive techniques | Edited session file or export | Smooth edits, no artefacts |
| 1.3 Apply basic EQ and compression | Processed audio with notes | Audible improvement with rationale |
| 1.4 Export to broadcast specification | Final WAV or MP3 file | Meets Rayd-yo spec sheet |

### Unit 2: Content Creation and Planning (Level 2, 3 credits)

**Learning Outcomes:**
1. Plan an audio programme for a target audience
2. Write and structure audio content
3. Present audio content confidently

**Assessment Criteria:**

| Criterion | Evidence Required | Pass Standard |
|-----------|-------------------|---------------|
| 2.1 Identify target audience and programme purpose | Written brief (500 words) | Clear audience and purpose stated |
| 2.2 Produce a running order | Timed running order document | All segments timed, totals correct |
| 2.3 Script or outline content | Script or bullet-point outline | Coherent structure, appropriate register |
| 2.4 Deliver a complete episode | Published episode (min 10 minutes) | Completed to running order |

### Unit 3: Publishing and Distribution (Level 2, 2 credits)

**Learning Outcomes:**
1. Publish audio content to a platform
2. Write metadata and show notes
3. Understand audience reach and analytics

**Assessment Criteria:**

| Criterion | Evidence Required | Pass Standard |
|-----------|-------------------|---------------|
| 3.1 Publish episode with correct metadata | Published episode with full metadata | All fields complete, accurate |
| 3.2 Write show notes | Show notes document | Min 200 words, accurate summary |
| 3.3 Interpret basic analytics | Screenshot plus written reflection | Identifies 3 meaningful data points |

## Grading

All units assessed on Pass/Refer basis. No grades — competence is the standard.

**Referral:** Assessor provides written feedback. Creator has 20 working days to resubmit.

**Appeal:** Follow standard appeals procedure (see quality-assurance/appeals-procedure.md).

## Assessment Methods

- **Portfolio of evidence** — primary method. Creator compiles evidence in their ILP.
- **Observation** — assessor witnesses live recording or broadcast session.
- **Professional discussion** — assessor questions creator on their process and decisions.

See quality-assurance/assessor-requirements.md for qualification and CPD requirements.

## Credit Recognition

Successful completion of all three units = 8 credits at Level 2. Maps to:
- Ofqual Level 2 Certificate equivalent (pending formal recognition)
- Wembley Wonders G-Tech Casters Builder badge
- ILP milestone: Audio Production competent
