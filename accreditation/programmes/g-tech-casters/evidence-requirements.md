# G-Tech Casters — Evidence Requirements

## What Counts as Evidence

Evidence must be authentic (created by the learner), sufficient (covers all criteria), current (produced during or after programme enrolment), and valid (directly demonstrates the criterion).

### Acceptable Evidence Types

| Type | Description | Units Covered |
|------|-------------|---------------|
| Audio recording (raw) | Unedited session recording | 1.1 |
| Edited audio file | Final exported episode | 1.2, 1.3, 1.4 |
| Session file screenshot | DAW session showing edit points | 1.2 |
| Processing notes | Written explanation of EQ/compression decisions | 1.3 |
| Programme brief | Written audience and purpose statement | 2.1 |
| Running order | Timed episode plan | 2.2 |
| Script or outline | Content structure document | 2.3 |
| Published episode | Live URL on Rayd-yo or equivalent | 2.4, 3.1 |
| Show notes | Published or draft episode description | 3.2 |
| Analytics screenshot | Platform data with written reflection | 3.3 |

## Storage and Submission

All evidence stored in creator ILP. Evidence portfolio submitted via platform assessment request. Assessor reviews within 10 working days.

## Authenticity Declarations

Creator signs authenticity declaration for each unit submission confirming:
- Work is their own
- Any collaboration is clearly identified
- AI-assisted content is declared and the creative decisions were theirs
