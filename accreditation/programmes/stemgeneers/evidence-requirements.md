## What Counts as Evidence

Evidence must be authentic (created by the learner), sufficient (covers all
criteria), current (produced during or after programme enrolment), and valid
(directly demonstrates the criterion).

For `STEM-APM`, "authentic" carries extra weight: a maths answer can be
copied. At least one worked calculation is witnessed live (assessment method
"Observation"), and the professional discussion probes the member's own
reasoning.

### Acceptable Evidence Types — STEM-APM

| Type | Description | Criteria Covered |
|------|-------------|------------------|
| Non-decimal notation exercise | 3 supplied values read and written in a supplied non-decimal system, with a note on what makes it a system | 1.1 |
| Ishango "honest sentence" | Written sentence/short paragraph naming the artefact and all three contested readings without resolving them | 1.2 |
| Numbered proof | One simple geometric result proved as a justified step-chain | 2.1 |
| Lever problem | A solved real load problem with working | 3.1 |
| Buoyancy / displacement work | Volume by displacement, or an upthrust calculation, with method | 3.2 |
| Bracketing (exhaustion) argument | A value or area bracketed between valid under- and over-estimates | 3.3 |
| Equation-solving algorithms | A linear and a simple quadratic equation solved, each written as a general numbered procedure | 4.1 |
| Algebra/algorithm account | Short written or recorded account of the shared root | 4.2 |
| Calculus worked set | Simple polynomials differentiated and integrated; a rate found from a derivative | 5.1 |
| Independent verification write-up | A real-stakes calculation checked by a different method, plus an account of why the check is trustworthy | 6.1 |
| Trust-model comparison | Written comparison of the Ifá and Katherine Johnson trust models, neither ranked | 7.1 |

*Not required here:* evidence for the Ifá cast-to-hex exercise itself — that
is produced and assessed under its own spec and only cross-referenced by
`STEM-APM` criterion 7.1.

## Storage and Submission

All evidence stored in the member's ILP. Portfolio submitted via platform
assessment request. Assessor reviews within 10 working days.

## Note on the Ishango evidence (criterion 1.2)

The pass condition is the **honesty of the claim**, not a correct conclusion —
there is no settled answer about what the Ishango bone's notches mean. Evidence
that asserts a single resolved reading (in either direction) is a refer, with
feedback pointing the member to state the dispute. This is the same discipline
as the Roots "Naming the Gap" skill, applied to a contested artefact rather
than a missing record.

## Authenticity Declarations

Member signs an authenticity declaration for each submission confirming:
- The mathematical working and written accounts are their own
- Any assistance received (a tutor, a peer, an ROV, a calculator or software
  tool) is declared, and the reasoning shown is the member's own
- AI-assisted work is declared and the method and interpretation were theirs
- For criterion 1.2: the member has represented the scholarly dispute
  accurately and has not resolved it beyond what the evidence supports
