# Centre Application Readiness Checklist

This checklist confirms Wembley Wonders CIC readiness to apply for recognised centre status with an awarding organisation.

## Quality Assurance
- [ ] Internal verification policy in place
- [ ] External verification policy in place
- [ ] Appeals procedure documented
- [ ] Assessor requirements documented
- [ ] CPD records system in place

## Staffing
- [ ] Lead internal verifier identified
- [ ] Assessors hold relevant qualifications (or working towards)
- [ ] Assessor occupational competence evidenced

## Resources
- [ ] Assessment records system operational (ILP platform)
- [ ] Evidence storage secure and accessible
- [ ] Learner induction process documented

## Programme Documentation
- [ ] Assessment criteria written for each programme
- [ ] Evidence requirements documented
- [ ] Unit mapping to qualification framework complete
- [ ] Marking and grading guidance produced

## Safeguarding and Compliance
- [ ] Safeguarding policy current and signed
- [ ] DBS checks in place for assessors
- [ ] Data protection policy (GDPR) current
- [ ] Equalities policy current
